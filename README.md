# Ханьцзы — персональный тренажёр китайских иероглифов

Веб-приложение для изучения мандарина с нуля с упором на **написание иероглифов от руки**.
Работает целиком в браузере: без бэкенда, без аккаунта, весь прогресс лежит локально.

## Что внутри

**Написание.** Основной режим — рисование иероглифа мышью или трекпадом в клетке 米字格.
Каждая черта проверяется по форме, направлению и порядку: неверная черта не засчитывается.
Проверку выполняет [hanzi-writer](https://hanziwriter.org/), сравнение приблизительное
(по совпадению траектории с эталонной медианой), а не пиксель-в-пиксель.

**Подбор иероглифов — не по HSK.** Следующий иероглиф выбирается по формуле, которая
взвешивает три вещи: частотность (ранг по списку Jun Da), количество черт и долю уже
знакомых компонентов. Иероглиф, собранный только из выученных частей, поднимается в
очереди — 好 приходит вскоре после 女 и 子. Уровень HSK показывается по клику, но на
порядок обучения не влияет. Формула — `src/lib/selection.ts`.

**Интервальные повторения.** SM-2 с двумя отклонениями: срыв роняет карточку до интервала
в 1 день, но не обнуляет ease factor; первые два успешных интервала фиксированы (1 и 3 дня).
Оценка 0–5 выводится из числа ошибок в написании и из того, пользовался ли ты подсказкой.
Реализация — `src/lib/srs.ts`.

**Структура занятия.** Разминка (созревшие повторения) → 3–7 новых иероглифов
(знакомство → обводка по контуру → написание по памяти) → тренировка → квиз
(значение→иероглиф, иероглиф→значение, на слух→иероглиф). Длина сессии 30/45/60 минут
задаёт количество новых и потолок повторений.

**Произношение.** Озвучка через Web Speech API. Запись с микрофона с распознаванием —
тоже через Web Speech API, с честным предупреждением прямо в интерфейсе: браузер
возвращает только текст, тоны он не разбирает, а ошибка в тоне часто всё равно
распознаётся как нужный иероглиф.

**Геймификация.** Streak, XP, уровни, тепловая карта активности, прогноз повторений на
неделю, разбивка колоды по зрелости. Намеренно сдержанно — мотивационный слой, а не фокус.

## Данные

800 самых частотных иероглифов, собранных из открытых источников (`npm run data`):

| Источник | Что берём | Лицензия |
|---|---|---|
| [hanziDB](https://github.com/ruddfawcett/hanziDB.csv) (список Jun Da) | ранг частотности, ключ, число черт, старый HSK | открытые данные |
| [makemeahanzi](https://github.com/skishore/makemeahanzi) | разложение на компоненты, этимологические подсказки | LGPL / Arphic Public License |
| [complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary) | пиньинь, значения, уровни HSK 3.0, примеры слов | CC-BY-SA (данные CC-CEDICT) |
| [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data) | траектории и порядок черт | LGPL / Arphic Public License |

Значения первых 240 иероглифов переведены на русский вручную (`scripts/ru-glosses.json`);
дальше показываются английские глоссы из датасета. Для многосложных чтений (多音字)
выбирается основное чтение по списку Jun Da, остальные показываются отдельной строкой.

## Локально

```bash
npm install
npm run dev          # http://localhost:5173/hanzi-trainer/
npm run build
npm run smoke        # логика: SRS, подбор, планировщик, целостность данных
npm run ui-check     # end-to-end в реальном Chrome, включая рисование черт
```

`npm run data` пересобирает датасет; ему нужны исходники в каталоге из `SRC_DIR`
и `hanzi-writer-data` в `node_modules`. `CHAR_LIMIT` меняет размер набора.

## Хранение прогресса

IndexedDB с дублем в localStorage. Ничего никуда не отправляется. В настройках есть
экспорт и импорт бэкапа — им стоит пользоваться перед сменой браузера или чисткой
данных сайта. Service worker кэширует приложение и данные о чертах, так что после
первой загрузки занятия работают офлайн (кроме распознавания речи — ему нужен интернет).

## Ограничения, о которых стоит знать

- Сверка написания приблизительная: она ловит порядок, направление и грубую форму черты,
  но не каллиграфическое качество.
- Распознавание речи не анализирует тоны и работает только в Chrome/Edge при наличии сети.
- Тёмная тема одна, светлой нет. Интерфейс рассчитан на большой экран.
